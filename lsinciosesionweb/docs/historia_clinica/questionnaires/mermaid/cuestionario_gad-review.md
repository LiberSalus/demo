# Cuestionario GAD-7 — Tabla de interpretación

Fuente: `index.DEMO_quewstionnaire.drawio`, pestaña **CUESTIONARIO GAD**.

## Escala

Generalized Anxiety Disorder 7-item scale (GAD-7). 7 ítems en flujo secuencial (g.1 → g.2 → ... → g.7). Cada ítem aporta de 0 a 3 puntos según la opción elegida:
- Ningún día = 0
- Varios días = 1
- Más de la mitad de los días = 2
- Casi todos los días = 3

Rango total posible: **0 a 21 puntos**.

## Tabla de Interpretación de Puntuación

| Puntuación | Interpretación |
|------------|----------------|
| 0-4        | Ansiedad mínima |
| 5-9        | Ansiedad leve |
| 10-14      | Ansiedad moderada |
| 15-21      | Ansiedad severa |
