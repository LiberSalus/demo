# Cuestionario HADS — Tabla de interpretación

Fuente: `index.DEMO_quewstionnaire.drawio`, pestaña **CUESTIONARIO HADS**.

## Escala

Hospital Anxiety and Depression Scale (HADS). 14 ítems en flujo secuencial
A.1 → D.1 → A.2 → … → A.7 → D.7. Cada ítem aporta 0-3 puntos según la
opción elegida (ver `cuestionario_hads.mmd`).

## Especificaciones

- **Ansiedad**: subpuntuación de los 7 ítems «A» (A.1 .. A.7). Rango 0-21.
- **Depresión**: subpuntuación de los 7 ítems «D» (D.1 .. D.7). Rango 0-21.

## Interpretación — Ansiedad

| Puntuación | Interpretación |
|------------|----------------|
| 0-7        | Normalidad     |
| 8-10       | Probable ansiedad |
| 11-21      | Caso de ansiedad |

## Interpretación — Depresión

| Puntuación | Interpretación |
|------------|----------------|
| 0-7        | Normalidad     |
| 08-10      | Probable depresión |
| 11-21      | Caso de depresión |
