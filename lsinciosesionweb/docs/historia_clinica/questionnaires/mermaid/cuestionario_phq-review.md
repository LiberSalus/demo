# Cuestionario PHQ-9 — Tabla de interpretación

Fuente: `index.DEMO_quewstionnaire.drawio`, pestaña **CUESTIONARIO PHQ**.

## Escala

Patient Health Questionnaire-9 (PHQ-9). 9 ítems en flujo secuencial (p.1 → p.2 → ... → p.9). Cada ítem aporta de 0 a 3 puntos según la opción elegida:
- Ningún día = 0
- Varios días = 1
- Más de la mitad de los días = 2
- Casi todos los días = 3

Rango total posible: **0 a 27 puntos**.

## Tabla de Interpretación de Puntuación

| Puntuación | Interpretación |
|------------|----------------|
| 0-4        | Depresión mínima |
| 5-9        | Depresión leve |
| 10-14      | Depresión moderada |
| 15-19      | Depresión moderadamente severa |
| 20-27      | Depresión severa |
